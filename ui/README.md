# @dynamind/terminal

Core runtime package for DynaMind Terminal.

This package is publishable for integrators who want DynaMind's agent loop, provider routing, MCP wiring, and runtime helpers in their own Node.js applications. Most users should install [`@dynamind/terminal-cli`](../cli/README.md) instead and use the `dynamind` command.

## Install

```bash
npm install @dynamind/terminal
```

## Scope

`@dynamind/terminal` is the supported runtime dependency behind the public CLI. It is not the canonical first-run install target for end users.
