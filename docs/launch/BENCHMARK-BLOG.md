# Building a safer trading-agent harness

DynaTrader 3.0 treats tools, providers, and agent capabilities as composable runtime boundaries. The release adds deterministic eval families for extraction, multi-hop research, spreadsheet work, and prompt-injection resistance.

The benchmark methodology compares a direct model baseline with the full harness across nine families and three local models. Results are intentionally omitted from this draft until the matrix is run and the generated traces are reviewed.
