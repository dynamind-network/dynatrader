# `@dyna/core`

The DynaTrader agent runtime and trading domain package. It provides the agent harness, memory and session services, market data interfaces, risk controls, execution routing, and plugin orchestration.

Install it as part of the DynaTrader package set. The supported end-user command line is provided by `dynatrader`.

```sh
bun add @dyna/core
```

See the repository README for setup, configuration, and API documentation.
