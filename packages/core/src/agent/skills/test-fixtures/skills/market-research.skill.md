When researching a new asset:
1. Check CoinGecko or CoinMarketCap for market cap and volume rankings.
2. Review GitHub commit activity for development health.
3. Analyze on-chain metrics: active addresses, transaction count, TVL.
4. Read the project whitepaper and tokenomics model.
5. Check recent news and regulatory developments.
