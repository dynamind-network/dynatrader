# @dynatrader/ink

DynaTrader's small, release-published Ink fork. It tracks upstream Ink 5.2.1 at commit `991aaa54eae39e1ad6d1964e747ea936d5a4ad12` and adds a terminal-grid selection API so TUI mouse navigation and text copying can work together.

Upstream source and license are retained in this package. Keep changes isolated to renderer/input behavior required by DynaTrader and rebase them deliberately when upgrading Ink.
